# HB-7: Find Bugs

* First try to find the defects through the UI, using standard testing methods
* Check what is already covered by tests and what is missing
* Then analyse the faulty part of the code
  * could the defect be fixed right away? under what conditions?
* Write a bug report
  * would you send such a report straight to the developers?
* A bug report helper is available in `docs/bug-reporting/`
